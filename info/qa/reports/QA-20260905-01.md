## Потребує виправлень

### QA-062-01 · VID-062 · P1 — новий unit suite не проходить

- Кроки: виконати `pnpm test` на перевіреному worktree.
- Очікувано: нові behavioral seams для manual replay проходять і підтверджують контракт.
- Фактично: 3 tests fail. «daily digest» fixture також має reminder о 07:45, тому implementation коректно обирає його раніше за digest 08:00. Два `toEqual` для finalize пропускають фактичний обов'язковий `deliveryId`; повний expected для start у першому test також пропускає `subscriptionId` і стане наступною помилкою після виправлення fixture.
- Доказ: `lib/public-push/admin-operations.test.ts`; Vitest exit 1, 3/118 failures.
- Вплив: обов'язковий test gate не пройдено; release заборонений.

### QA-062-02 · VID-062 · P1 — PostgreSQL DATE показується попереднім днем

- Кроки: у isolated schema записати manual delivery із `scheduled_date='2026-09-09'`, відкрити `/admin/push` адміністратором.
- Очікувано: «09.09.2026 · 08:00».
- Фактично: «08.09.2026 · 08:00».
- Причина: `lib/public-push/repository.ts` конвертує отриманий `Date` через `toISOString().slice(0, 10)`, і локальна північ PostgreSQL DATE зміщується UTC-конверсією.
- Вплив: operational log відображає неправильну календарну дату найближчого повідомлення; реліз фічі заборонений.
