# RELEASE-20260828-02 — підготовка VID-010–VID-017

Запит VID-018: «перевір і залий». Цей документ описує операції основного агента, а не підмінює незалежний QA. Початковий gate і блокування нижче збережено як історію; актуальне рішення наведено в наступному розділі.

## Прямий дозвіл на публікацію без додаткової перевірки

28.08.2026 користувач уточнив: «давай перевірку не роби а роби лише деплой і залиття на гіт». Дозволено одноразовий реліз VID-010–VID-017 без невиконаного genuine browser zoom 200% і без повторного QA. Незалежний звіт залишається BLOCKED лише на цьому критерії; PASS йому не приписано. Продуктовий код після ретесту незмінний.

Реліз через push у main та чинну Vercel Git integration; `pnpm test && pnpm build` зберігається. Локальні тести / build / браузер / live smoke / runtime error scan не запускаються повторно за вказівкою користувача. Операційний контроль: не опублікувати секрети, дочекатися READY і відповідності Git SHA. Жодних production-міграцій, змін env або доменів.

Стан на момент підготовки коміту: публікація в роботі; остаточний SHA і статус буде записано після завершення. Production URL: https://vidmitka.vercel.app/. Framework: Next.js; target: production. Drains: 0 за попередньою read-only перевіркою; runtime scan і післярелізний QA пропущено за прямим запитом.

## Поточний стан

QA у роботі. Commit, push і deployment цього пакета ще не виконані. Після PASS потрібно звірити відбиток, перевірити staged-файли / секрети, зробити звичайний push, дочекатися READY саме нового SHA, виконати read-only live smoke та bounded scan runtime logs. FAIL / BLOCKED / NOT_RUN забороняють публікацію.

Після checkpoint першого QA основний агент реалізував пакет QA-03-01–QA-03-04: назви пошукових вікон, узгоджений groupMode після reset, desktop-only стилі згортання та inline-підказка порожнього журналу без flex-колонок. Виправлення торкаються шести файлів UI, не серверних правил / БД / залежностей. Статичний diff чистий; потрібен повторний незалежний QA. Невирішений browser200% залишається обов'язковим, користувач написав «далі», але не погодив його відкладення. Drains0; після можливого deployment доступні штатні Vercel logs / Analytics, зовнішній збір логів не налаштовано.

Підсумкові докази та невиконаний справжній200% — у [QA-20260828-03](QA-20260828-03.md). Перехід до штатного settings UI для200% закрив тестовий browser context; масштаб не змінений, CSS/pinch/profile обхід не використовувався.

Через відсутність повного QA PASS commit / push / deployment **не виконані**. Право GitHub push підтверджено read-only, але воно не обходить QA-gate. Для продовження потрібна підтримана або ручна незалежна перевірка200% чи явне рішення користувача відкласти лише цей критерій; після зміни обсягу потрібен оновлений висновок QA. Чинний сайт не змінювався.
