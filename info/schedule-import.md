# Імпорт розкладу викладача

## Призначення

Викладач або адміністратор у власному викладацькому просторі може пакетно додати свої заняття з файлу JSON або CSV. Імпорт доступний лише схваленому користувачу; власник завжди визначається з поточної сесії й не передається у файлі.

## Обов'язкові поля

| Значення | JSON | CSV українською | Допустимі значення |
| --- | --- | --- | --- |
| Предмет | `subject` | `предмет` | Точна назва активного предмета |
| Аудиторія | `room` | `аудиторія` | Точна назва активної аудиторії |
| День | `day` | `день` | Назва українською або англійською чи номер 1–7 |
| Номер пари | `period` | `пара` | Номер активної пари 1–99 |
| Тип тижня | `weekType` | `тиждень` | `чисельник`, `знаменник`, `обидва тижні` або відповідні технічні значення |

Додаткове поле: **тип заняття** — `lessonType` / `lessonTypeName` у JSON, `тип заняття` у CSV. Назва має відповідати активному типу з довідника адміністратора (порівняння без урахування регістру; пробіли нормалізуються). Тип заняття не замінює `weekType`. Старий файл без цього поля або з порожньою клітинкою сумісний; заняття лишається без типу. Заповнене некоректне, невідоме або неактивне значення скасовує весь імпорт. Додати тип до старого заняття можна у «Моїх заняттях» без повторного імпорту. Стан доповнення — [upcoming-lessons.md](upcoming-lessons.md).

CSV може використовувати кому або крапку з комою як роздільник. Значення з комою дозволяється брати в подвійні лапки; подвійна лапка всередині значення записується двічі.

Готові приклади доступні викладачу на сторінці «Імпорт розкладу»:

- `/examples/schedule-import-example.json`;
- `/examples/schedule-import-example.csv`.

## Правила перевірки

- файл повинен мати розширення `.json` або `.csv`;
- максимальний розмір — 512 КБ;
- один файл може містити не більше 200 занять;
- предмет, аудиторія й номер пари повинні відповідати активним довідникам;
- переданий тип заняття також вибирається з активного довідника, імпорт не створює нові типи;
- усі рядки належать поточному викладачу;
- чисельник і знаменник одного слота не конфліктують;
- тип «обидва тижні» конфліктує і з чисельником, і зі знаменником;
- викладач не може мати два заняття в одному слоті;
- одна аудиторія не може бути зайнята двома викладачами в одному слоті.

Імпорт є атомарним: якщо хоча б один рядок некоректний або конфліктний, жодне заняття з файлу не зберігається. Після успішного імпорту заняття відображаються в розділі «Мої заняття».
