# Вільні аудиторії за парою — VID-053

## Мета

Дати користувачу публічного розкладу швидку відповідь, які аудиторії вільні на вибрану дату й номер пари, не додаючи окремої сторінки або нового фільтра.

## Візуальна й контентна модель

- Візуальна теза: компактна біла службова поверхня над сіткою з тонкою теплою межею та одним бірюзовим акцентом.
- Контент: номер і час пари, дата, підсумок «вільно з усіх активних», далі короткий список назв аудиторій.
- Взаємодія: 44 px кнопка навколо чинного кольорового номера; короткий spinner під час запиту; стандартне позиціонування, Escape і повернення фокусу Base UI Popover.

## Правило доступності

Джерело кандидатів — усі активні записи `schedule_rooms`. Зайнятими вважаються назви аудиторій усіх нескансованих `PublicScheduleItem` із тим самим `periodNumber` у повному денному resolver без фільтра викладача або групи. Отже календарні перенесення, зміни аудиторії та актуальні винятки враховуються тим самим правилом, що й публічна сітка; скасовані заняття аудиторій не блокують.

Порядок довідника зберігається. Заняття без вказаної аудиторії не впливають на перелік. Неактивні аудиторії не повертаються навіть тоді, коли вони згадані історичним заняттям.

## Межі модулів

- `lib/schedule-v2/free-rooms.ts` — чисте правило й тип результату, придатне для unit-тесту.
- `listPublicRooms()` — мінімальний серверний read активного довідника.
- `GET /api/public/free-rooms?date=YYYY-MM-DD&periodNumber=N` — валідований read-only endpoint для browser-driven popup.
- `components/free-room-popover.tsx` — локальний UI-стан запиту; основний explorer не отримує дубль повного розкладу.
