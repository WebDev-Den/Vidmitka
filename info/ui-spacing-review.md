## Перевірена поведінка

- `/dashboard` без сесії відповідає перенаправленням на `/sign-in`.
- `/approval-pending` та `/dashboard/teachers` без сесії також перенаправляють на `/sign-in`.
- Публічні `/` та `/schedule` доступні без автентифікації.
- Поля Clerk мають українські видимі назви та українські placeholder-и.
- На mobile закрита бічна панель має `visibility: hidden`, тому її приховані посилання не потрапляють у клавіатурний порядок.
- Великі таблиці не збільшують ширину документа.
- Browser console не має помилок застосунку. Є очікуване попередження Clerk про development keys; воно не з'являється з production keys.

## Автентифікований smoke-тест

Спроба створити тимчасового тестового користувача не завершилася через недоступний DNS-вузол Cloudflare Turnstile у локальному браузерному середовищі. Запит на створення користувача не відбувся; Backend API підтвердив 0 користувачів із тестовою адресою. Рольова навігація викладача й адміністратора перевіряється unit-тестами. Картку очікування перевірено у реальному браузері на фактичних стилях застосунку з репрезентативним вмістом; повний authenticated smoke-тест потрібно повторити після входу реального користувача.
