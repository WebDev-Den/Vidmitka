# VID-036 — фільтр публічного розкладу за викладачем

## Рішення

У центрі панелі публічного розкладу додається один компактний список: «Всі викладачі» та активні викладачі за абеткою. Початковий стан не обмежує розклад. Конкретний вибір записується у GET-параметр `teacher`, тому посилання можна відкрити повторно, а Back / Forward повертає попередній стан.

## Функціональна межа

- Фільтр працює однаково для одного дня та цілого тижня.
- Усі переходи публічного розкладу зберігають вибраного викладача.
- Фільтрація виконується на сервері до формування read-model, а не приховуванням карток у браузері.
- Для базового заняття береться список `schedule_entry_teachers`. Якщо активний виняток містить власних викладачів, саме він є джерелом істини.
- Для перенесених і разових занять застосовується та сама логіка фактичного викладача.
- Неактивного або невідомого викладача не можна залишити активним у UI: сторінка повертається до «Всі викладачі».
- Вибір груп не повертається; групи залишаються контекстом картки за VID-035.

## Візуальна теза

Один нейтральний білий select у чинній академічній панелі, без нової картки, іконкової декорації або нової палітри. На desktop він займає вільний центр між датами; на вузьких екранах переходить у повний рядок. Висота контролу — 44 px, межа та focus відповідають чинним полям.

## TDD-межі й відкладений QA

Під час фінального пакетного QA:

1. Repository повертає всіх активних викладачів в алфавітному порядку.
2. Фільтр одного викладача повертає його базові, перенесені й разові заняття та не повертає чужі.
3. Заміна викладача у винятку змінює належність заняття до фільтра; порожня заміна використовує базовий список.
4. «Всі викладачі», невідомий UUID і невалідний параметр не приховують загальний розклад у публічному UI.
5. День / тиждень, вкладки дат, стрілки, «Сьогодні» і date form зберігають `teacher`.
6. Browser QA перевіряє keyboard, auto-submit, Back / Forward, console, loading feedback і overflow на 1440 / 820 / 390 px.

До прямого запиту «перевір» або перед дозволеним релізом QA не запускається.
