# Адаптація `my-schedule` для Vidmitka

Стан: **реалізовано локально; пакетний QA не запускався (`NOT_RUN`); зміни не опубліковані.**

## Рішення

`D:\morpz\my-schedule` використовується як референс публічного робочого простору, а не копіюється як окремий Vite-застосунок. Так зберігаються вже перевірені серверні модулі Vidmitka: PostgreSQL, календар тижнів, винятки, імпорт, сесія адміністратора та захищені маршрути.

## Що переносимо

- щільний вертикальний розклад із окремою колонкою номера й часу пари;
- швидку навігацію днями поточного тижня;
- явний стан чисельника / знаменника;
- паралельні заняття в одному часовому слоті;
- позначення поточної й наступної пари;
- компактні метадані предмета, типу, аудиторії та викладача;
- адаптивний повноекранний робочий ритм без великих промо-блоків.

## Що замінюємо

- зовнішній Google Apps Script API → чинний серверний repository розкладу v2;
- вибір викладача → видимий список і пошук груп;
- клієнтське визначення тижня → централізовані налаштування семестру Vidmitka;
- локальний кеш як джерело істини → URL-параметри та серверна вибірка;
- Vite SPA → Next.js App Router із Server Component сторінкою та малими інтерактивними Client Components;
- темну синьо-фіолетову тему → затверджену теплу бірюзову палітру й канонічний логотип.

## Модулі й шви

Глибокий серверний модуль `public-schedule` приховує SQL, правила тижнів і винятків за трьома інтерфейсами: список активних груп, список активних пар, розклад дня/тижня. Публічна сторінка знає лише серіалізовані групи, пари та заняття.

Інтерактивний workspace відповідає тільки за пошук груп, реальний час і доступні mobile-панелі. Зміна групи, дати або режиму є навігацією URL; сервер заново формує правильний розклад. Адмінка є окремим захищеним модулем і не залежить від публічної композиції.

## Візуальна теза

Спокійне академічне табло: тепла основа Vidmitka, щільна газетна сітка пар і один бірюзовий статусний акцент. Головний візуальний якір — поточний день із послідовністю всіх пар, а не hero або набір dashboard-карток.

## Контентний план

1. Компактний brand header.
2. Поточний час, дата, навчальний тиждень і режим день/тиждень.
3. Навігація днями.
4. Список груп із пошуком і вибраним станом.
5. Вертикальна сітка пар із заняттями та винятками.

## Інтеракційна теза

- URL-переходи групи/дня мають чинний loading feedback Next.js.
- Поточна пара оновлюється раз на хвилину без декоративної анімації.
- Mobile список груп відкривається як компактна панель, закривається Escape і повертає фокус; `prefers-reduced-motion` поважається.

## QA-черга

- active/empty group list і пошук;
- день/тиждень, понеділок–неділя, чисельник/знаменник;
- порожня, одна й кілька паралельних пар;
- скасування, перенесення й зміна аудиторії;
- поточна/минула/наступна пара;
- 1440, 820, 390 px; keyboard, focus, console, локальний і document overflow.
