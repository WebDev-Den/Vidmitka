## Перевірена поведінка

- `/dashboard` без сесії відповідає перенаправленням на `/sign-in`.
- `/approval-pending` та `/dashboard/teachers` без сесії також перенаправляють на `/sign-in`.
- Публічні `/` та `/schedule` доступні без автентифікації.
- Поля власної форми входу мають українські видимі назви.
- На mobile закрита бічна панель має `visibility: hidden`, тому її приховані посилання не потрапляють у клавіатурний порядок.
- Великі таблиці не збільшують ширину документа.
- Browser console не має помилок застосунку.

## Автентифікований smoke-тест

Рольова навігація викладача й адміністратора перевіряється unit-тестами. Після переходу на власну автентифікацію повний authenticated smoke-тест виконується через локальну БД без зовнішньої CAPTCHA або DNS-залежності.

Нових console errors / warnings не виявлено; тимчасовий viewport override після перевірки скинуто.
